# 智慧树课后题记录器 v1

在电脑浏览器里做完智慧树某一章的课后测验后，进入「本次成绩 / 查看答案解析」页，点面板「**▶ 开始记录**」，脚本自动把该章**题目 + 正确答案**存入本地题库；每章点一次自动累计（跨章节、按题干去重、选项乱序变体保留）；攒够后点「**存为 Word**」导出 .docx。

纯本地运行：不联网、不自动答题、不刷视频进度。

## 文件

| 文件 | 说明 |
| --- | --- |
| `zhihuishu-recorder.user.js` | **主脚本（只装这一个；已内置页面结构侦察/诊断）** |
| `test/unit.test.js` | 纯函数单元测试（`node test/unit.test.js`） |

## 安装（两种任选）

**方式 A（推荐）导入文件**：Tampermonkey → 管理面板 → 实用工具 → 「导入」→ 选 `zhihuishu-recorder.user.js`。

**方式 B 粘贴代码**：Tampermonkey → 管理面板 → 「+」新建脚本 → 全选删除默认内容 → 把 `zhihuishu-recorder.user.js` 的**全部内容**粘贴进去 → Ctrl+S 保存。脚本自带 `==UserScript==` 头，保存后油猴会自动识别名称/匹配域名/权限。

安装后打开任意 `*.zhihuishu.com` 页面刷新，右下角出现面板「智慧树课后题记录器」（绿色操作提示在左下角）。

## 使用流程

1. 电脑浏览器登录智慧树 → 打开课程 → 做完**一章**课后测验并交卷。
2. 进入「本次成绩 / 查看答案解析」页（能看到题目+答案的那页）。
3. 面板会**自动识别课程名与当前章节**：章节名 = 所在章 + 该章第一个单元名（如 `第1章 消化系统 · 1.1 口腔与牙齿`），点进别的章节/单元会自动更新。
   - 识别不对就手动改一下；**改过之后以你手动的为准**（不再被自动覆盖），点「清空本课」可恢复自动识别。
4. 点「**▶ 开始记录**」→ 绿色提示：本章新增 N 题 / 变体 / 跳过重复 / 解析失败 X 题 / 该课累计 Y 题。
   - 快捷键 Ctrl+Shift+X 等同点按钮。
5. 下一章做完后在对应页面再点一次，自动累计去重。
6. 想导出时点「**存为 Word**」→ 下载 `课程名.docx`（真实 .docx，Word/WPS 可打开）。
7. 换课：改面板「课程名」框后记录即归属新课；「清空本课」删除当前课程全部记录（二次确认）。
8. 面板会**记住**课程名/章节名与已记录的题目：切换章节、切换页面（页面重载/换框架）后自动恢复，不会丢；点「**📚 已记录**」可查看本课全部题目（可复制保存）。**只有**「清空本课」会删除记录与记忆。

## 识别不到/识别错时（重要）

v1 的题目识别是**泛化规则**（按"含答案标记的容器 + 题干/选项/答案行结构"解析），不依赖单一 class 名，能覆盖大多数布局；但每所学校课程页面排版可能不同。已内置的兼容处理（v1.5.2）：

- **答案行**：`正确答案：X` 与 `答案：X` 两种写法都识别（自动忽略「我的答案/您的答案」）；
- **题干净化**：自动去掉界面文案（AI答题辅导 / 收藏为薄弱题 / 笔记…）、题型标签（单选/判断题）与表情符号；
- **选项错位**：选项文字与 A/B/C/D 字母分行显示时，会自动把文字配回对应字母；
- **答题卡**：页面上的「答题卡 / 答案汇总」区会被识别并跳过，不会当成题目记录。
- **标题/导航**：课程名/学期标题、目录项、既无选项又无答案的空壳块也会跳过（如 `医学英语2(26-27学年第一学期)` 不会被当成题目）。

遇到以下情况：

- 点「开始记录」提示"未识别到带答案的题目块"，或提示新增 0 题、解析失败数很大；
- 录进去的题干/选项/答案残缺。

请点面板「**🔍 诊断**」→ 「复制到剪贴板」→ 把快照**完整粘贴回聊天**发给我，我据快照微调识别规则（通常只改一处选择器，几分钟）。

诊断快照是一份综合报告，含四部分（已排除脚本自身面板文字）：

1. **基本信息**：页面 URL / 标题 / 是否顶层 frame / 输入框数量 / 正文长度（判断内容是否在 iframe 里）；
2. **题库识别**：找到的题目容器及其解析结果（题干/题型/选项数/答案）；
3. **页面结构侦察**：按 class/id 关键词命中的候选元素与含 `correct/answer` 等标记的元素（方便校准选择器）；
4. **运行错误**：脚本运行期间捕获到的错误/警告（若弹窗/识别异常，这里会直接写出来）。

> 说明：v1.3.0 起已把原先独立的 `zhihuishu-recorder-scout.user.js` 侦察能力**合并进主脚本**，只维护这一个文件；旧的侦察脚本可以卸载删除。

## 自动遍历（v1.5.0 起）

面板「**🤖 自动遍历**」会按下面顺序自动操作，读完或你点「⏹ 停止遍历」为止：

1. 当前页有题目 → 自动读取保存（去重累计）→ 点「下一题/下一页」，否则点「退出/返回」；
2. 没题目但有「查看解析」→ 点开；
3. 有「去提升/开始提升」→ 进入；
4. 都没有 → 在侧边目录里点「当前项」的下一项（切下一个视频/节点）；
5. 仍找不到 → 日志提示，你手动切页后它会继续。

**安全边界（重要）**：

- 只自动化「浏览 + 读取页面上已经显示的题目/解析」，**不答题、不提交**；
- 内置黑名单：**永不点击**含「提交/交卷/上交/放弃/结束/删除/清空」的按钮（防误点影响成绩）；
- 每步间隔约 1.6 秒、最多 400 步自动停，随时可手动停止；
- 按钮靠文案匹配（白名单），各校页面文案不同；跑不动时把**面板底部日志**或「🔍 诊断」快照发我，我据实校准。
- 页面上的「**答题卡 / 答案汇总**」区会被自动识别并跳过，不会被当作题目记录。
- 自动化批量操作可能触发平台风控，是否使用及后果请自行判断。

## 数据存哪

所有记录存在 Tampermonkey 的脚本存储里（`GM_setValue`，跨智慧树各子域共享），不在网页 localStorage、不会随清理浏览器缓存丢失。导出 Word 不影响数据；「清空本课」才会删除。

## 安全边界

- 脚本只在 `*.zhihuishu.com` 页面运行（@match），只读你在成绩/解析页已展示的内容。
- 不替你答题、不刷视频进度、不看答案前不交卷。
- 涉及"查看解析后锁定重做"的课程，请自行判断查看时机。
