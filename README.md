# 智慧树课后题记录器（开发中）

目标：你在电脑浏览器里做完智慧树某一章的课后测验后，在「本次成绩 / 查看答案解析」页面上点一下按钮，脚本自动把该章题目 + 正确答案记录成本地题库（JSON），并可另存为 Word 文档。纯本地运行，不做自动答题、不刷视频进度。

## 侦察版安装（一次）

1. 浏览器（Chrome/Edge）装好 Tampermonkey（油猴）扩展。
2. 点油猴图标 → 「管理面板」→ 顶部「实用工具」标签 → 下方「导入」→ 选择文件 → 选本目录的 `zhihuishu-recorder-scout.user.js` → 确认安装。
3. 打开任意智慧树课程页面刷新一下，页面右下角应出现蓝色小按钮「🔍 侦察本页」。

## 侦察取证步骤（请你配合做一次）

1. 电脑浏览器登录智慧树 → 打开你要整理的课程 → 做完**一章**课后测验并交卷。
2. 进入显示本章成绩 / 可查看答案解析的那个页面（通常点「本次成绩」或本章测验标题进入）。
3. 如果页面上有弹窗、iframe 等，**在能看到题目内容的那个页面上**点右下角「🔍 侦察本页」。
4. 弹出报告窗口后点「复制报告」，把内容**完整粘贴回聊天**发给我。

我会依据报告确定题目的 DOM 选择器，然后开发 v1 完整版。

## 安全与边界

- 脚本只在你打开智慧树页面时运行（@match 仅 *.zhihuishu.com），纯本地分析、不联网、不上传。
- 不使用脚本替你答题、不看视频不交卷，仅读取你自己交卷后页面已展示的内容。
- 开发完成后侦察版可随时在油猴里停用/卸载。
