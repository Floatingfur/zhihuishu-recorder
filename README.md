# 智慧树课后题记录器 v1

在电脑浏览器里做完智慧树某一章的课后测验后，进入「本次成绩 / 查看答案解析」页，点面板「**▶ 开始记录**」，脚本自动把该章**题目 + 正确答案**存入本地题库；每章点一次自动累计（跨章节、按题干去重、选项乱序变体保留）；攒够后点「**存为 Word**」导出 .docx。

纯本地运行：不联网、不自动答题、不刷视频进度。

## 文件

| 文件 | 说明 |
| --- | --- |
| `zhihuishu-recorder.user.js` | **主脚本（只装这一个；已内置页面结构侦察/诊断）** |
| `test/unit.test.js` | 纯函数单元测试（`node test/unit.test.js`） |

## 安装（两种任选）

**方式 A（推荐）导入文件**：Tampermonkey → 管理面板 → 实用工具 → 「导入」→ 选 `zhihuishu-recorder.user.js`。

**方式 B 粘贴代码**：Tampermonkey → 管理面板 → 「+」新建脚本 → 全选删除默认内容 → 把 `zhihuishu-recorder.user.js` 的**全部内容**粘贴进去 → Ctrl+S 保存。脚本自带 `==UserScript==` 头，保存后油猴会自动识别名称/匹配域名/权限。

安装后打开任意 `*.zhihuishu.com` 页面刷新，右下角出现面板「智慧树课后题记录器」（绿色操作提示在左下角）。

## 使用流程

1. 电脑浏览器登录智慧树 → 打开课程 → 做完**一章**课后测验并交卷。
2. 进入「本次成绩 / 查看答案解析」页（能看到题目+答案的那页）。
3. 面板会**自动识别课程名与当前章节**：章节名 = 所在章 + 该章第一个单元名（如 `第1章 消化系统 · 1.1 口腔与牙齿`），点进别的章节/单元会自动更新。
   - 识别不对就手动改一下；**改过之后以你手动的为准**（不再被自动覆盖），点「清空本课」可恢复自动识别。
4. 点「**▶ 开始记录**」→ 绿色提示：本章新增 N 题 / 变体 / 跳过重复 / 解析失败 X 题 / 该课累计 Y 题。
   - 快捷键 Ctrl+Shift+X 等同点按钮。
5. 下一章做完后在对应页面再点一次，自动累计去重。
6. 想导出时点「**存为 Word**」→ 下载 `.docx`（真实 .docx，Word/WPS 可打开；题库里有多门课时按「课程 → 章节」分组）。
7. 换课：改面板「课程名」框（它只是题目的标签）后新记录就归到新课；「清空本课」只删当前课程标签那些题（二次确认）。
8. 面板会**记住**课程名/章节名，点「**📚 已记录**」可查看/复制题库全部题目。
   - **v1.8.0 起：题目统一存在一个题库里，课程名/章节名只是每条题的标签**。所以换视频、换页面、换框架、识别到的课程名变化，都**不可能**再出现“上一个视频的题目没了”；只有你点「清空本课」（且带二次确认）才会删记录。状态栏会显示 `题库共 N 题；本课已记录 M 题，覆盖 K 个章节`，随时确认总数。
   - **一打开就有题？** 那是 v1.8.0 把旧版按课程名分库存的题目**自动并入**题库的结果（为了不丢你之前记录的真题）。不想要就在面板点「**🧹 清空题库**」（二次确认）——会把整个题库清空，并记下标记让旧数据**不再被导入**；只想删当前课程那一批就点「清空本课」。

## 识别不到/识别错时（重要）

v1 的题目识别是**泛化规则**（按"含答案标记的容器 + 题干/选项/答案行结构"解析），不依赖单一 class 名，能覆盖大多数布局；但每所学校课程页面排版可能不同。已内置的兼容处理：

- **答案行**：`正确答案：X` 与 `答案：X` 两种写法都识别（自动忽略「我的答案/您的答案」）；
- **选项内容**（v1.8.2 修复）：下面几种写法都能读到选项文字——`A. teeth`、`A teeth`（字母与文字间无标点）、字母单独一行而文字在下一行（`A` ↵ `teeth`）、一行里挤了多个选项（`A. 甲  B. 乙  C. 丙`）。判断顺序：先严格解析，拿不到选项文字时自动走宽松解析（字母必须 A、B、C… 连续才认，避免把以 `A ` 开头的英文题干误当选项）；
- **字母块 / 文字块被拆开**（v1.8.4 修复）：真机上常见「题干行尾夹着选项词、下面一整块 `A.` `B.` `C.` `D.`」，或「字母块在前、文字块在后」。现在会先做配对预处理：字母块 A、B、C… 依次对上后面的 N 行/一行 N 个短词/上一行结尾的 N 个短词（并把词从题干里摘掉）。——以前这种会错位成 `A. 空 B. 空 C. 空 D. rectum`，答案也跟着飞到错项上；
- **选项一行一个**（v1.8.4）：`📚 已记录` 与导出的 Word 都是每行一个选项（`A. cecum` / `B. appendix` / …），不再挤在一行；
- **题目块识别**（v1.8.2 修复）：容器筛选会先剔除“只有答案行、没有题干”的碎块——否则它会连带把父级题目块一起排除，导致那一道题完全不记录；容器 class 不带 `question/item` 等关键词时，手动「开始记录」也会自动走宽松识别；
- **题干净化**：自动去掉界面文案（AI答题辅导 / 收藏为薄弱题 / 笔记…）、题型标签（单选/判断题）与表情符号；
- **选项错位**：选项文字与 A/B/C/D 字母分行显示时，会自动把文字配回对应字母；
- **答题卡**：页面上的「答题卡 / 答案汇总」区会被识别并跳过，不会当成题目记录。
- **标题/导航**：课程名/学期标题、目录项、既无选项又无答案的空壳块也会跳过（如 `医学英语2(26-27学年第一学期)` 不会被当成题目）。

遇到以下情况：

- 点「开始记录」提示"未识别到带答案的题目块"，或提示新增 0 题、解析失败数很大；
- 录进去的题干/选项/答案残缺。

请点面板「**🔍 诊断**」→ 「复制到剪贴板」→ 把快照**完整粘贴回聊天**发给我，我据快照微调识别规则（通常只改一处选择器，几分钟）。

诊断快照是一份综合报告，含四部分（已排除脚本自身面板文字）：

1. **基本信息**：页面 URL / 标题 / 是否顶层 frame / 输入框数量 / 正文长度（判断内容是否在 iframe 里）；
2. **题库识别**：找到的题目容器及其解析结果（题干/题型/选项数/答案）；
3. **页面结构侦察**：按 class/id 关键词命中的候选元素与含 `correct/answer` 等标记的元素（方便校准选择器）；
4. **运行错误**：脚本运行期间捕获到的错误/警告（若弹窗/识别异常，这里会直接写出来）。

> 说明：v1.3.0 起已把原先独立的 `zhihuishu-recorder-scout.user.js` 侦察能力**合并进主脚本**，只维护这一个文件；旧的侦察脚本可以卸载删除。

## 自动遍历（v1.5.0 起）

面板「**🤖 自动遍历**」会按下面顺序自动操作，读完或你点「⏹ 停止遍历」为止：

1. **去提升**进入提升/练习界面 → 自动点「**查看解析**」（智慧树必须先查看解析才能看到答案）；
2. 当前页有题目 → 自动读取保存（去重累计）；有「下一题/下一页」就先翻页；
3. 读完 → 点**退出**回到视频页，并标记该视频已完成（**每个视频的「去提升」只进一次**）；
4. 回到视频页 → **直接切到下一个视频/节点**，再重复 1~3，直到课程最后一个视频；
5. 已到目录最后一节、连续多次找不到可操作项、或同一按钮连点 8 次无效 → 自动停止（日志说明原因）。

### 不会“中途断掉”（v1.8.1）

- **页面跳转自动续跑**：点「下一节/下一个视频」在智慧树上常常是**整页刷新**，脚本会被重建。运行状态（当前节点位置、日志）会实时存到 `zhr.pilot.auto`，刷新后自动接着跑，**不需要再点一次**（面板日志会写`检测到上次的自动遍历，正在续跑…`）。
- **卡住就跳过，不停止**：某个视频点不动（同一按钮连点 8 次无效）→ 记一条日志后**跳过它、继续下一个**；切不到下一个节点时每 3 次打一条进度日志并**继续重试**（最多 20 次）。
- 真正会停止的情况：**课程跑完**（目录到最后一节）、你点「⏹ 停止遍历」、或长时间确实无任何可操作项。

兼容性处理：按钮查找会**同时扫描同源 iframe**；点击会派发完整鼠标事件序列（`pointerdown/mousedown/pointerup/mouseup/click`，适配只认 pointerdown 的页面）；无文字的关闭/返回**图标按钮**（class/title/aria-label 含 close/exit/back）也能识别。

**安全边界（重要）**：

- 只自动化「浏览 + 读取页面上已经显示的题目/解析」，**不答题、不提交**；
- 内置黑名单：**永不点击**含「提交/交卷/上交/放弃/结束/删除/清空」的按钮（防误点影响成绩）；
- 每步间隔约 1.6 秒、最多 400 步自动停，随时可手动停止；
- 按钮靠文案匹配（白名单），各校页面文案不同；跑不动时把**面板底部日志**或「🔍 诊断」快照发我，我据实校准。
- **课程名**优先读页面**左上角**那一块文字（如 `医学英语2(26-27学年第一学期)`）；**章节名**读左侧目录当前项 + 第一个单元名。
- 自动切换下一个视频时，先试左侧目录，再试页面上的「下一节/下一个」按钮；两者都找不到时，日志会写出**现场诊断**（左栏候选容器数/最多子项/可见子项）并**最多重试一次就停**，不会死在一个视频里反复进出。
- **v1.7.4**：目录/课程名/章节名识别改为**跨同源 iframe 扫描**（左侧目录常和面板不在同一个 frame 里）；目录识别不强依赖 class 名，并允许折叠隐藏的子项。
- 页面上的「**答题卡 / 答案汇总**」区会被自动识别并跳过，不会被当作题目记录。
- 自动化批量操作可能触发平台风控，是否使用及后果请自行判断。

## 数据存哪

所有记录存在 Tampermonkey 的脚本存储里（`GM_setValue`，跨智慧树各子域共享），不在网页 localStorage、不会随清理浏览器缓存丢失。存取结构：

- `zhr.v2.bank` —— **唯一题库**：所有题目（每条带 `course` 课程名标签 + `chapter` 章节名标签）
- `zhr.v2.migrated` —— 旧数据（`zhr.v1.course.*`）并入新题库的标记
- `zhr.v1.ui.course` / `zhr.v1.ui.chapter` —— 面板里记住的课程名/章节名（手改后带 `.manual=1`）
-（旧的 `zhr.v1.course.*` / `zhr.v1.index` 是 v1 分库遗留，已不写入，仅保留可回退）

导出 Word 不影响数据；「清空本课」只删当前课程标签那一批，「🧹 清空题库」才删全部（两者都是二次确认）。

## 安全边界

- 脚本只在 `*.zhihuishu.com` 页面运行（@match），只读你在成绩/解析页已展示的内容。
- 不替你答题、不刷视频进度、不看答案前不交卷。
- 涉及"查看解析后锁定重做"的课程，请自行判断查看时机。
